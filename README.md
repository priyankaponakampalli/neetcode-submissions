# NeetCode Practice

This repository contains my solutions to the NeetCode problems I’m solving while preparing for coding interviews and strengthening my problem-solving skills.

I’m working through the list step by step, mainly using Java, and focusing on understanding the approach rather than just getting the code to pass.

## What I’m Practicing

* Arrays & Hashing
* Two Pointers
* Sliding Window
* Stack
* Binary Search
* Linked Lists
* Trees
* Tries
* Heap / Priority Queue
* Backtracking
* Graphs
* Advanced Graphs
* 1-D & 2-D Dynamic Programming
* Greedy
* Intervals
* Math & Geometry
* Bit Manipulation

## My Approach

For each problem, I try to:

1. Understand the problem and constraints
2. Think through the approach before coding
3. Implement the solution in Java
4. Analyze the time and space complexity
5. Improve the solution when possible

## Progress

This is an ongoing repository. I’m still working through the NeetCode list and adding solutions as I solve them.

The goal isn’t just to complete a list of problems, but to become more comfortable with problem-solving patterns that can be applied to new coding questions.
